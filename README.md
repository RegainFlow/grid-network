# Grid Infrastructure Analytics Platform

**Description:** Automated system that detects anomalies in utility and industrial grid infrastructure. Monitors thousands of sensor nodes to identify irregularities and potential failures. By cleaning historical telemetry and training a custom model, deployed into a live dashboard, it cut manual operator review by 80% and enabled faster incident response.

**Tags:**
- 5K+ Sensor Streams
- 80% Manual Review Reduction
- Real-Time Dashboards

## Run Locally

**Prerequisites:** Node.js

- Install dependencies: `npm install`
- Run the app: `npm run dev`
